# Jobbby UI web — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consegnare la spec in 6 PR incrementali. Questo documento contiene la tabella di marcia e il piano dettagliato della **PR 1**; il piano di ogni PR successiva viene scritto e aggiunto qui all'inizio di quella PR, sul codice reale prodotto dalle precedenti.

**Architecture:** La logica di `Program.cs` diventa `JobbbyRunner` in `src/Host`, guidato da `JobbbySettings` (`settings.json` in `DataDir`). La CLI resta e lo chiama. Il `GraphEngine` riceve la cancellazione nei nodi. Adzuna cerca per paese e zona, con ricerca remota opzionale e prefiltrata.

**Tech Stack:** .NET 8, xUnit 2.4, System.Text.Json, Adzuna REST API, `claude -p`.

**Spec:** `docs/superpowers/specs/2026-09-30-web-ui-design.md` (revisione 3).

## Global Constraints

- Nessun riferimento a professioni, paesi o alla ricerca del proprietario nel codice, nei default o nei prompt.
- `DataDir` da `Jobbby:DataDir`; nessun percorso del container nel codice.
- Scritture di `settings.json`, `cursors.json`, `applications.json`, `runs/*.json`: file temporaneo + rename.
- CLI e Web girano solo nel container; un solo processo per `DataDir` (lock `.jobbby.lock`, `FileShare.None`).
- Nessun `salary_min` / `salary_include_unknown` inviato ad Adzuna; retribuzione filtrata solo nello stage 1.
- Testo degli annunci e del CV sempre delimitato nei prompt; `claude -p` con `--tools ""`.
- Telegram resta compilato e testato; non si cancella nulla.
- Build senza warning, tutti i test verdi a ogni commit.

## Review Focus

1. `settings.json` scritto a mano con un campo sconosciuto o un tipo sbagliato → errore leggibile con il nome del campo, non un'eccezione di deserializzazione.
2. `area.where` con spazi/accenti ("Reggio nell'Emilia") → URL con encoding corretto, nessuna ricerca rotta.
3. Due query che producono lo stesso annuncio tra ricerca locale e ricerca remota → valutato una volta sola.
4. `Ctrl+C` durante una run CLI → processo `claude` terminato, cursori non scritti per le ricerche non completate.
5. CLI lanciata due volte → la seconda esce subito con codice ≠ 0 e il messaggio del lock, senza toccare file.

Ogni voce ha il suo test nel task indicato (1 → Task 2, 2 → Task 4, 3 → Task 5, 4 → Task 1 e Task 8, 5 → Task 3).

public async Task RunAsync_CancelledDuringNode_PropagatesAndStops()
{

    definition.RegisterNode("slow", new TokenCapturingNode(_ => cts.Cancel(), delay: Timeout.InfiniteTimeSpan));

    definition.RegisterEdge("slow", _ => "never");

private sealed class TokenCapturingNode(Action<CancellationToken> onExecute, TimeSpan? delay = null) : INode
{
    public async Task<NodeResult> ExecuteAsync(GraphState state, CancellationToken cancellationToken = default)
    {
        onExecute(cancellationToken);
        if (delay is not null)
            await Task.Delay(delay.Value, cancellationToken);
        return NodeResult.From(new Dictionary<string, object>());
    }
}
